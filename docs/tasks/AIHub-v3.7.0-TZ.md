# ТЗ — AIHub v3.7.0: новый интерфейс + автопилот сети

Дата: 2026-09-24 · Статус: на утверждение · База: AIHub v3.6.0

## 1. Цель

Привести AIHub к уровню мобильных LLM-приложений (Gemini / ChatGPT / Claude):
современный интерфейс, живой чат с агентами, боковое меню с чатами; плюс автономная
работа сети без ручных команд. Делаем всё сразу, одним релизом.

## 2. Что получает владелец

1. Стиль Gemini (Material: крупные скругления, «пилюли», мягкие акценты), тема авто
   (день/ночь, как в Telegram), стартовая анимация — сборка логотипа AIHub из частиц,
   показывается, пока грузятся данные.
2. Каркас как в Gemini/GPT/Claude: нижняя навигация, переключатель систем в шапке,
   боковое меню с историей чатов.
3. Чаты: единый список (Все · DSH · OpenCode), создание в один тап,
   переименование/удаление/закрепить/архив, поиск внутри чата, экспорт текста.
4. Живой чат: лента сообщений + поле ввода + «стоп»; действия агента сохраняются.
5. Вкладка DSH — настоящий интерфейс внутри приложения; OpenCode — свой экран;
   «Ещё» — все текущие функции (статусы, метрики, настройки, защита).
6. Автоназвания: технические названия заменяются человеческими (бесплатная модель);
   существующие чаты — бэкфилл.
7. Автопилот: сеть сама настраивается/чинится, бот отвечает на Start, умные
   напоминания, одна команда `go.sh`.

## 3. A — Интерфейс (переработка static/)

- A1. Стиль: Gemini-подобный Material; авто-тема (Telegram/система); день и ночь;
  скругления/«пилюли»; аккуратные микроанимации; `prefers-reduced-motion` уважается.
- A2. Сплэш: сборка логотипа AIHub из частиц; виден, пока грузятся данные;
  адаптация под тему; плавный переход в интерфейс; не дольше ~2 с.
- A3. Шапка: лого/название + сегмент-переключатель `Все · DSH · OpenCode` (всегда виден),
  мини-индикаторы статусов.
- A4. Нижняя навигация: `Чаты · DSH · OpenCode · Ещё` (иконки + подписи, safe-area).
- A5. Боковое меню (свайп/кнопка слева, как в Gemini/GPT/Claude): «+ Новый чат», поиск,
  «Закреплённые», «Архив», история с группировкой (Сегодня / Вчера / 7 дней / Раньше),
  внизу — настройки.
- A6. Список чатов: единый; строка: название, бейдж системы, точка статуса, время,
  превью последнего сообщения; меню/свайп: закрепить, переименовать, архив, удалить
  (с подтверждением).
- A7. Экран чата: лента (роли, код, время) + поле ввода + «стоп»; в шапке —
  модель/проект/статус; действия: approve/deny/permission, answer_question,
  change_model, fork, revert (все текущие); поиск по чату; экспорт текста.
- A8. Вкладка DSH: встроенный DSH web внутри приложения (iframe через существующий
  прокси), кнопка «открыть отдельно», понятные ошибки.
- A9. Вкладка OpenCode: свой экран в стиле AIHub (сессии OpenCode + чат как A7).
- A10. Вкладка «Ещё»: всё текущее — статусы DSH/OpenCode, метрики/circuit, порты,
  настройки, диагностика, kill switch, подтверждения дорогих действий, ссылки/URL.
- A11. Паритет: всё, что есть сейчас, остаётся (сверяется по текущему UI).

## 4. B — Чаты (клиент + бэкенд)

- B1. Создание: «+» → быстрый чат; система — по текущему фильтру (на «Все» — выбор
  DSH/OpenCode).
- B2. Переименование: OpenCode — уже есть; DSH — реализовать (сейчас нет).
- B3. Удаление: обе системы (DSH DELETE уже есть) + подтверждение.
- B4. Закрепление/Архив: локально в AIHub (`data/pins.json`); системы не трогаем.
- B5. Автонейминг: только технические названия (ID/даты/«Сессия ДД.ММ»); имя 2–4 слова
  по содержимому через бесплатную модель (`space-bunny-free` через OpenCode); просмотр:
  первые сообщения/модель/проект; fallback — первая строка первого сообщения; бэкфилл
  существующих; кэш; вручную названные — не трогать.
- B6. Поиск внутри чата + экспорт текста (буфер / скачать .txt).

## 5. C — DSH / OpenCode (техника вкладок)

- DSH: iframe same-origin (в ответах уже X-Frame-Options: SAMEORIGIN; если DSH пришлёт
  свой DENY — переопределять в прокси), WebSocket уже поддержан.
- OpenCode: только данные через API (своего веб-интерфейса у системы нет).

## 6. D — Автопилот сети (полная спецификация)

- D1. Автонастройка Serve: bounded wait (CLI умеет «висеть»); «Serve is not enabled» →
  ссылка в бота; HTTPS-сертификаты → ссылка; accept-dns выключен → автофикс;
  чужой конфиг не трогать; выключатели `TAILSCALE_AUTOSERVE`, `TAILSCALE_AUTODNS`.
- D2. Классификация клиента (loopback/lan/tailscale/other) → `data/netstate.json` →
  `/health last_channel` → `status.sh`.
- D3. Бот-диалог: `/start`, `/link` (только владелец; статус; кнопки-ссылки; skip старого
  бэклога; пауза мастера `.tg_poll_pause`).
- D4. Напоминания ≤1 раза/24 ч (телефон не виден и не заходил по LAN; `TAILSCALE_REMIND`).
- D5. `scripts/go.sh` — одна команда запуска.
- D6. Кнопка в Telegram: ставить и как default, и явно в чат владельца.

## 7. E — Качество

- Тесты: unit на всё новое (классификация, разбор serve, напоминания, бот, автонейминг,
  pins, DSH rename); регресс 111+; smoke; acceptance 14/0.
- Безопасность: бот — только владелец; без Funnel; секреты не логируются;
  SECRET_PATH не печатать.
- Доки: README, RUNBOOK, NETWORK_TAILSCALE, COMPLIANCE; VERSION/CHANGELOG → 3.7.0.
- Публичный репозиторий AIHub обновить без персональных данных; живую установку
  обновить и проверить.

## 8. Этапы (один релиз; порядок реализации)

1. Каркас UI: сплэш, навигация, шапка, боковое меню, список чатов (паритет) —
   промежуточная проверка на телефоне.
2. Чаты: экран чата с вводом, действия (pin/archive/rename/delete), поиск/экспорт,
   автонейминг + бэкфилл, DSH rename (бэкенд).
3. Вкладки DSH/OpenCode/«Ещё» + паритет всех функций.
4. Автопилот (D1–D6).
5. Тесты, доки, релиз 3.7.0, деплой, пуш.

## 9. Приёмка

- [ ] Внешний вид как Gemini; день/ночь; сплэш из частиц (пока грузятся данные).
- [ ] Нижняя навигация и шапка-переключатель работают.
- [ ] Боковое меню: создать/поиск/закрепить/архив/переименовать/удалить.
- [ ] Чат: сообщения видны, отправка и «стоп» работают; поиск и экспорт.
- [ ] DSH встроен; экран OpenCode; «Ещё» — все старые функции на месте.
- [ ] Технические названия заменены; вручную названные не тронуты.
- [ ] Автопилот: сам поднимает Serve; ссылка при «не включён»; напоминания ≤1/сутки.
- [ ] `go.sh`, тесты, smoke, acceptance — зелёные; живая установка работает;
      публичный репо обновлён.

## 10. Вне рамок

- PWA/иконка на домашний экран (только Telegram).
- Управление агентами из бота.
- Funnel/публичный доступ.
